Pasta de download dos arquivos ZIP da Receita Federal.

* `./download_files.sh AAAA-MM [pasta]` baixa todos os ZIPs da competência (ex.: `./download_files.sh 2026-10`).
* `./unzip_files.sh [pasta_zips] [pasta_destino]` descompacta os ZIPs. Por padrão, os desta pasta vão para `../extracted`.

Passo a passo completo em [docs/carga.md](../../../docs/carga.md).
