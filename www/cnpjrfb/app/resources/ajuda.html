Visão Geral
Sistema web em PHP, feito com o Adianti Framework, para consultar os dados públicos do CNPJ publicados pela Receita Federal do Brasil: empresas, estabelecimentos, sócios, Simples/MEI e tabelas de apoio.

Desde a versão 2.0.0 o sistema usa o layout de dados que a RFB adotou em 2021. Código-fonte e documentação: github.com/bjverde/cnpjrfb.

Agradecimento para todas as pessoas que contribuíram de forma direta ou indireta para o projeto. Abaixo alguns nomes de destaque, pois o sistema de consulta foi baseado nos scripts de carga de dados das pessoas abaixo. Sem essas pessoas o trabalho seria bem mais difícil:

  • Até a versão 1.2.0, Fabio Serpa - CNPJ-full
Projetos irmãos
  • bjverde/CNPJ-full (Python): converte os arquivos da RFB em SQLite ou CSV, faz consultas e gera o grafo de relacionamentos entre empresas e sócios. Usa o mesmo modelo de banco deste sistema.
  • aphonsoar/Receita_Federal_do_Brasil_-_Dados_Publicos_CNPJ (Python): baixa os arquivos e faz a carga no PostgreSQL.
  • fabioserpa/CNPJ-full (Python): projeto original do CNPJ-full, para o layout antigo da RFB.

Sobre o Grafo
Desde a versão 2.0.0 a geração do grafo está desativada no sistema. O grafo é gerado pelo CNPJ-full, que já foi atualizado para o layout novo da RFB e permite consultar empresas ou sócios e gravar o resultado em CSV ou em grafo de relacionamentos. A integração com este sistema ainda está em andamento.
